## 1. Executive Overview

### Vision
Fully automated unauthorized software remediation pipeline that:
- **Listens** to incoming emails from authorized security team
- **Parses** software details (name, version, removal reason)
- **Detects** the software across all system paths (C:\Program Files, C:\Program Files (x86), registry, AppData, etc.)
- **Identifies** the specific version(s) and validates removal safety
- **Removes** ONLY the notified version using a privileged service account
- **Verifies** successful removal and reports outcomes
- **Logs** everything for audit and continuous improvement

### Key Requirements
```
✓ MCP Email Server (Gmail/Office 365 integration)
✓ AI Agent (Claude) to orchestrate workflow
✓ Multi-path software detection (registry, file system, WMI)
✓ Version-specific removal (not all versions)
✓ Service account with elevated permissions
✓ Atomic operations (all-or-nothing removal)
✓ Automatic rollback on failure
✓ DEX Sentinel integration for outcome measurement
✓ Audit trail for compliance
✓ User notification (sentiment-optimized)
```

### High-Level Flow
```
EMAIL RECEIVED
    ↓
MCP EMAIL SERVER reads & notifies
    ↓
AI AGENT orchestrates
    ├─ Parse email → extract software details
    ├─ Validate against whitelist
    ├─ Detect installations across all paths
    ├─ Get service account credentials (encrypted)
    └─ Determine removal strategy
    ↓
SOFTWARE DETECTION ENGINE
    ├─ Registry scan (HKLM, HKCU)
    ├─ File system scan (Program Files, Program Files x86, AppData)
    ├─ WMI/MSI query
    ├─ Running processes check
    └─ Version comparison → match to email version
    ↓
SERVICE ACCOUNT EXECUTION
    ├─ Create system restore point
    ├─ Uninstall via MSI / manual removal
    ├─ Clean registry entries
    ├─ Delete residual files
    └─ Verify removal complete
    ↓
VALIDATION & VERIFICATION
    ├─ Re-scan file system
    ├─ Re-scan registry
    ├─ Verify no running processes
    └─ Signature of removal
    ↓
OUTCOME LOGGING
    ├─ Success/failure to DEX Sentinel
    ├─ Telemetry impact (boot time, performance)
    ├─ User notification
    └─ Alert security team
```

from typing import TypedDict
import email
from email.mime.text import MIMEText

import asyncio

class EmailMetadata(TypedDict):
    message_id: str
    sender: str
    subject: str
    received_time: str
    software_name: str
    software_version: str
    device_ids: list[str]
    removal_reason: str
    urgency: str  # "critical", "high", "medium", "low"
    attachments: list[dict]

class MCPEmailServer:
    """
    MCP Tool: Email monitoring and extraction
    Listens for unauthorized software notifications and extracts metadata
    """
    
    def __init__(self):
        self.email_service = self._init_email_service()
        self.whitelist = self._load_sender_whitelist()
        self.event_queue = asyncio.Queue()
        self.last_check = None
        
    def _init_email_service(self):
        """Initialize Gmail API, Office 365, or IMAP connection"""
        # Option 1: Gmail API
        # Option 2: Office 365 REST API
        # Option 3: IMAP (generic)
        pass
    
    def _load_sender_whitelist(self) -> list[str]:
        """Load authorized email addresses from config"""
        return [
            "security-team@company.com",
            "it-compliance@company.com",
            "vulnerability-scanner@company.com"
        ]
    
    async def poll_emails(self, interval_seconds: int = 300):
        """
        Poll for new emails every N seconds
        Only process emails from whitelisted senders
        """
        while True:
            try:
                # Connect to email service
                new_emails = self.email_service.search(
                    q="subject:([UNAUTHORIZED-SOFTWARE] OR [SECURITY-PATCH] OR [EOL-SOFTWARE])",
                    after=self.last_check,
                    from_=self.whitelist
                )
                
                for email_msg in new_emails:
                    metadata = self._parse_email(email_msg)
                    if metadata:
                        await self.event_queue.put({
                            "type": "unauthorized_software_detected",
                            "payload": metadata,
                            "timestamp": datetime.now().isoformat()
                        })
                
                self.last_check = datetime.now()
                await asyncio.sleep(interval_seconds)
                
            except Exception as e:
                # Log error, continue polling
                print(f"Email polling error: {e}")
                await asyncio.sleep(60)  # Retry sooner on error
    
    def _parse_email(self, email_msg) -> EmailMetadata:
        """
        Parse email to extract:
        - Software name, version
        - Target device IDs
        - Removal reason
        - Urgency
        
        Email format example:
        ───────────────────────────────────────
        Subject: [UNAUTHORIZED-SOFTWARE] .NET 6.0.36 Requires Immediate Removal
        From: security-team@company.com
        
        Software: Microsoft .NET Runtime
        Version: 6.0.36
        Status: End-of-Life (Nov 12, 2024)
        Risk Level: CRITICAL
        Urgency: IMMEDIATE (24 hours)
        
        Affected Devices:
        - Device IDs: DEV-0042, DEV-0043, DEV-0044
        - OS: Windows 10/11 Enterprise
        - Department: Engineering, Finance
        
        Removal Action:
        Uninstall .NET 6.0.36 from both 64-bit and 32-bit locations
        Replace with: .NET 8.0.16 LTS
        
        Reason: Security vulnerability CVE-2024-21XX
        Expected Impact: +15% boot time improvement
        ───────────────────────────────────────
        """
        
        try:
            subject = email_msg.get("subject", "")
            body = email_msg.get_payload()
            sender = email_msg.get("from", "")
            
            # Validate sender
            if not any(s in sender for s in self.whitelist):
                return None
            
            # Extract structured data from email body (regex or NLP)
            metadata = {
                "message_id": email_msg.get("message-id", str(uuid.uuid4())),
                "sender": sender,
                "subject": subject,
                "received_time": email_msg.get("date", datetime.now().isoformat()),
                "software_name": self._extract_field(body, "Software:"),
                "software_version": self._extract_field(body, "Version:"),
                "device_ids": self._extract_device_ids(body),
                "removal_reason": self._extract_field(body, "Reason:"),
                "urgency": self._extract_urgency(subject, body),
                "attachments": self._extract_attachments(email_msg)
            }
            
            # Validate required fields
            if metadata["software_name"] and metadata["software_version"]:
                return metadata
            
            return None
            
        except Exception as e:
            print(f"Email parsing error: {e}")
            return None
    
    def _extract_field(self, body: str, field_name: str) -> str:
        """Extract field value from email body"""
        import re
        pattern = f"{field_name}\\s+([^\\n]+)"
        match = re.search(pattern, body, re.IGNORECASE)
        return match.group(1).strip() if match else ""
    
    def _extract_device_ids(self, body: str) -> list[str]:
        """Extract device IDs (DEV-XXXX pattern)"""
        import re
        return re.findall(r'DEV-\d{4}', body)
    
    def _extract_urgency(self, subject: str, body: str) -> str:
        """Determine urgency level"""
        urgency_keywords = {
            "critical": ["CRITICAL", "IMMEDIATE", "URGENT", "24 hours"],
            "high": ["HIGH", "ASAP", "1 week"],
            "medium": ["MEDIUM", "2 weeks"],
            "low": ["LOW", "30 days"]
        }
        
        combined = f"{subject} {body}".upper()
        for level, keywords in urgency_keywords.items():
            if any(kw in combined for kw in keywords):
                return level
        return "medium"
    
    def _extract_attachments(self, email_msg) -> list[dict]:
        """Extract attachments (remediation runbooks, etc.)"""
        attachments = []
        for part in email_msg.walk():
            if part.get_content_disposition() == "attachment":
                attachments.append({
                    "filename": part.get_filename(),
                    "content_type": part.get_content_type(),
                    "size_bytes": len(part.get_payload())
                })
        return attachments

# software_detector.py

class SoftwareDetectionEngine:
    """
    Comprehensive software detection across all Windows system paths
    Handles registry, file system, WMI, and running processes
    """
    
    def __init__(self):
        self.detected_locations = {}
    
    def scan_all_paths(self, software_name: str, target_version: str = None) -> dict:
        """
        Scan all possible installation paths for a software
        Returns all instances, versions, and locations
        """
        
        results = {
            "software_name": software_name,
            "scan_time": datetime.now().isoformat(),
            "instances_found": []
        }
        
        # 1. Registry scan (HKLM and HKCU)
        results["instances_found"].extend(
            self._scan_registry(software_name, target_version)
        )
        
        # 2. File system scan (Program Files and variations)
        results["instances_found"].extend(
            self._scan_filesystem(software_name, target_version)
        )
        
        # 3. WMI/MSI Database scan
        results["instances_found"].extend(
            self._scan_wmi(software_name, target_version)
        )
        
        # 4. Running processes check
        results["running_processes"] = self._check_running_processes(software_name)
        
        return results
    
    def _scan_registry(self, software_name: str, target_version: str = None) -> list:
        """
        Scan Windows registry for software installations
        
        Standard registry paths:
        - HKLM\\Software\\Microsoft\\Windows\\CurrentVersion\\Uninstall
        - HKLM\\Software\\Wow6432Node\\Microsoft\\Windows\\CurrentVersion\\Uninstall (x86 on x64)
        - HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Uninstall
        """
        
        import winreg
        instances = []
        
        registry_paths = [
            (winreg.HKEY_LOCAL_MACHINE, r"Software\Microsoft\Windows\CurrentVersion\Uninstall"),
            (winreg.HKEY_LOCAL_MACHINE, r"Software\Wow6432Node\Microsoft\Windows\CurrentVersion\Uninstall"),
            (winreg.HKEY_CURRENT_USER, r"Software\Microsoft\Windows\CurrentVersion\Uninstall"),
        ]
        
        for hive, path in registry_paths:
            try:
                with winreg.OpenKey(hive, path) as key:
                    for i in range(winreg.QueryInfoKey(key)[0]):
                        subkey_name = winreg.EnumKey(key, i)
                        
                        with winreg.OpenKey(key, subkey_name) as subkey:
                            try:
                                display_name = winreg.QueryValueEx(subkey, "DisplayName")[0]
                                version = winreg.QueryValueEx(subkey, "DisplayVersion")[0]
                                install_location = winreg.QueryValueEx(subkey, "InstallLocation")[0]
                                uninstall_string = winreg.QueryValueEx(subkey, "UninstallString")[0]
                                
                                # Check if this matches our software
                                if self._matches_software(display_name, software_name):
                                    if not target_version or self._version_matches(version, target_version):
                                        instances.append({
                                            "detection_method": "registry",
                                            "registry_hive": "HKLM" if hive == winreg.HKEY_LOCAL_MACHINE else "HKCU",
                                            "registry_key": f"{path}\\{subkey_name}",
                                            "display_name": display_name,
                                            "version": version,
                                            "install_location": install_location,
                                            "uninstall_string": uninstall_string,
                                            "uninstall_method": "msi" if ".msi" in uninstall_string else "exe"
                                        })
                            except WindowsError:
                                pass
            except WindowsError:
                pass
        
        return instances
    
    def _scan_filesystem(self, software_name: str, target_version: str = None) -> list:
        """
        Scan file system for software installations
        
        Common paths:
        - C:\\Program Files
        - C:\\Program Files (x86)
        - C:\\ProgramData
        - %APPDATA%
        - %LOCALAPPDATA%
        """
        
        import os
        import re
        
        instances = []
        scan_paths = [
            "C:\\Program Files",
            "C:\\Program Files (x86)",
            "C:\\ProgramData",
            os.path.expandvars("%APPDATA%"),
            os.path.expandvars("%LOCALAPPDATA%")
        ]
        
        software_keywords = software_name.lower().split()
        
        for scan_path in scan_paths:
            if not os.path.exists(scan_path):
                continue
            
            try:
                for root, dirs, files in os.walk(scan_path):
                    # Check directory name matches software
                    if any(kw in root.lower() for kw in software_keywords):
                        
                        # Look for version files
                        for file in files:
                            if file in ["version.txt", "version.ini", "about.txt"]:
                                filepath = os.path.join(root, file)
                                version = self._extract_version_from_file(filepath)
                                
                                if not target_version or self._version_matches(version, target_version):
                                    instances.append({
                                        "detection_method": "filesystem",
                                        "root_path": root,
                                        "version_file": filepath,
                                        "version": version,
                                        "file_count": len(files),
                                        "total_size_mb": sum(
                                            os.path.getsize(os.path.join(root, f)) 
                                            for f in files if os.path.isfile(os.path.join(root, f))
                                        ) / (1024 * 1024)
                                    })
            except Exception as e:
                print(f"Error scanning {scan_path}: {e}")
        
        return instances
    
    def _scan_wmi(self, software_name: str, target_version: str = None) -> list:
        """
        Scan WMI for installed software
        Uses Win32_Product class which is more reliable for MSI packages
        """
        
        import wmi
        instances = []
        
        try:
            wmi_conn = wmi.WMI()
            products = wmi_conn.Win32_Product(Name=f"%{software_name}%")
            
            for product in products:
                version = product.Version
                
                if not target_version or self._version_matches(version, target_version):
                    instances.append({
                        "detection_method": "wmi",
                        "wmi_name": product.Name,
                        "wmi_vendor": product.Vendor,
                        "version": version,
                        "install_location": product.InstallLocation,
                        "install_date": product.InstallDate,
                        "package_cache": product.PackageName,
                        "uninstall_via_msi": True
                    })
        except Exception as e:
            print(f"WMI scan error: {e}")
        
        return instances
    
    def _check_running_processes(self, software_name: str) -> list:
        """
        Check for any running processes related to the software
        IMPORTANT: Cannot remove if processes are running
        """
        
        import psutil
        running_processes = []
        
        software_exes = [
            f"{keyword}.exe" 
            for keyword in software_name.lower().split()
        ]
        
        for proc in psutil.process_iter(['pid', 'name', 'exe']):
            try:
                if any(exe in proc.info['name'].lower() for exe in software_exes):
                    running_processes.append({
                        "pid": proc.info['pid'],
                        "name": proc.info['name'],
                        "exe_path": proc.info['exe']
                    })
            except (psutil.NoSuchProcess, psutil.AccessDenied, psutil.ZombieProcess):
                pass
        
        return running_processes
    
    def _matches_software(self, display_name: str, software_name: str) -> bool:
        """Check if display name matches software name"""
        return all(
            keyword.lower() in display_name.lower() 
            for keyword in software_name.split()
        )
    
    def _version_matches(self, found_version: str, target_version: str) -> bool:
        """
        Compare versions
        Handle formats like:
        - 6.0.36
        - 6.0.36 (x64)
        - 6.0.36-rc
        """
        
        # Extract numeric version
        import re
        found_num = re.match(r'[\d.]+', found_version).group() if found_version else ""
        target_num = re.match(r'[\d.]+', target_version).group() if target_version else ""
        
        return found_num == target_num
    
    def _extract_version_from_file(self, filepath: str) -> str:
        """Extract version from text file"""
        try:
            with open(filepath, 'r') as f:
                content = f.read()
                import re
                match = re.search(r'version\s*[:=]\s*([\d.]+)', content, re.IGNORECASE)
                return match.group(1) if match else "unknown"
        except:
            return "unknown"

class SoftwareRemovalEngine:

        """

        3. Uninstall via MSI (if available)
        4. Delete remaining files
        5. Clean registry
        6. Verify removal
        """

        }

            # Step 2: Stop running processes
            running = self._stop_running_processes(software_name)
            results["processes_stopped"] = len(running)
            
            # Step 3: Process each installation
            for installation in installations:
                inst_result = self._remove_installation(installation, target_version)

            results["remaining_instances"] = remaining

            results["rollback_available"] = True

        return results

        try:

                result["steps"].append(self._uninstall_via_msi(installation))
            
            # Method 2: EXE Uninstall
            elif installation.get("uninstall_string"):
                result["steps"].append(self._uninstall_via_exe(installation))
            
            # Method 3: Manual File Deletion
            if installation.get("root_path") or installation.get("install_location"):

            # Method 4: Registry Cleanup

    def _uninstall_via_msi(self, installation: dict) -> dict:
        """Uninstall using MSI Uninstall string"""
        
        uninstall_string = installation.get("uninstall_string", "")
        
        # Extract GUID from uninstall string
        import re
        guid_match = re.search(r'\{[A-F0-9]{8}-[A-F0-9]{4}-[A-F0-9]{4}-[A-F0-9]{4}-[A-F0-9]{12}\}', uninstall_string)
        
        if guid_match:
            guid = guid_match.group()
            cmd = f'msiexec /x {guid} /qn /norestart'
            
            result = self._execute_as_service_account(cmd)
            self.removal_log.append(f"MSI uninstall executed: {guid}")
            
            return {
                "method": "msi_uninstall",
                "guid": guid,
                "exit_code": result.get("exit_code"),
                "status": "completed" if result.get("exit_code") == 0 else "failed"
            }
        else:
            return {
                "method": "msi_uninstall",
                "status": "skipped",
                "reason": "No MSI GUID found"
            }
    
    def _uninstall_via_exe(self, installation: dict) -> dict:
        """Uninstall using uninstall EXE"""
        
        uninstall_exe = installation.get("uninstall_string", "")
        
        # Extract EXE path and flags
        import re
        exe_match = re.match(r'"([^"]+)"(.*)', uninstall_exe)
        
        if exe_match:
            exe_path = exe_match.group(1)
            flags = exe_match.group(2).strip()
            
            # Add silent flags if not present

                }
            
            # Delete registry key (with service account privileges)
            cmd = f'reg delete "{key_path}\\{key_to_delete}" /f'
            result = self._execute_as_service_account(cmd)
            
            self.removal_log.append(f"Registry cleaned: {registry_key}")
            
            return {
                "method": "registry_cleanup",
                "key": registry_key,
                "status": "completed"
            }
        
        except Exception as e:
            return {
                "method": "registry_cleanup",
                "status": "failed",
                "error": str(e)
            }
    
    def _verify_removal(self, software_name: str, target_version: str) -> list:
        """Verify software was completely removed"""
        
        detector = SoftwareDetectionEngine()
        remaining = detector.scan_all_paths(software_name, target_version)
        
        self.removal_log.append(f"Verification: {len(remaining['instances_found'])} instances remain")
        
        return remaining["instances_found"]
    
    def _execute_as_service_account(self, cmd: str) -> dict:
        """Execute command with service account credentials"""
        
        import subprocess
        import base64
        
        # Create PowerShell command that uses stored credentials
        ps_cmd = f"""
$pass = ConvertTo-SecureString '{self.creds['password']}' -AsPlainText -Force
$cred = New-Object System.Management.Automation.PSCredential ('{self.creds['username']}', $pass)
Invoke-Command -ScriptBlock {{ {cmd} }} -Credential $cred
        """
        
        result = subprocess.run(
            ["powershell", "-Command", ps_cmd],
            capture_output=True,
            text=True
        )
        
        return {
            "exit_code": result.returncode,
            "stdout": result.stdout,
            "stderr": result.stderr
        }

# credential_manager.py

class ServiceAccountCredentialManager:
    """
    Manages encrypted credentials for elevated software removal operations
    Uses Azure Key Vault / HashiCorp Vault for secure storage
    """
    
    def __init__(self, vault_type: str = "azure"):
        self.vault_type = vault_type
        self.vault_client = self._init_vault()
    
    def _init_vault(self):
        """Initialize vault client"""
        
        if self.vault_type == "azure":
            from azure.identity import DefaultAzureCredential
            from azure.keyvault.secrets import SecretClient
            
            credential = DefaultAzureCredential()
            client = SecretClient(
                vault_url=os.getenv("AZURE_KEYVAULT_URL"),
                credential=credential
            )
            return client
        
        elif self.vault_type == "hashicorp":
            import hvac
            client = hvac.Client(
                url=os.getenv("VAULT_ADDR"),
                token=os.getenv("VAULT_TOKEN")
            )
            return client
    
    def get_service_account_credentials(self, 
                                      service_account_name: str,
                                      required_permissions: list[str]) -> dict:
        """
        Retrieve service account credentials
        
        Requirements:
        - Account must have: SeServiceLogonRight, SE_RESTORE_NAME, SE_BACKUP_NAME
        - Minimum permissions for software removal:
          * Registry: HKEY_LOCAL_MACHINE delete
          * File system: C:\Program Files delete
          * Services: Stop/start services
          * WMI: Execute Win32_Product methods
        """
        
        # Retrieve from vault
        if self.vault_type == "azure":
            secret = self.vault_client.get_secret(f"svc-{service_account_name}-creds")
            credentials_json = secret.value
        
        elif self.vault_type == "hashicorp":
            response = self.vault_client.secrets.kv.read_secret_version(
                path=f"it-secret/service-accounts/{service_account_name}"
            )
            credentials_json = response['data']['data']
        
        credentials = json.loads(credentials_json)
        
        # Validate permissions
        self._validate_permissions(service_account_name, required_permissions)
        
        # Create temporary token (expires in 30 minutes)
        credentials['temporary_token'] = self._create_temporary_token(
            service_account_name,
            validity_seconds=1800
        )
        
        # Log access
        self._audit_log_credential_access(
            service_account_name,
            "credential_retrieved",
            required_permissions
        )
        
        return credentials
    
    def _validate_permissions(self, service_account_name: str, required_permissions: list[str]):
        """
        Validate service account has required permissions
        
        Check against Active Directory groups:
        - "SoftwareRemoval_RegistryDelete"
        - "SoftwareRemoval_FileDelete"
        - "SoftwareRemoval_ServiceControl"
        """
        
        from ldap3 import Server, Connection, ALL
        
        server = Server(os.getenv("LDAP_SERVER"), get_info=ALL)
        conn = Connection(server, user=service_account_name, password="***")
        
        if not conn.bind():
            raise PermissionError(f"Cannot bind as {service_account_name}")
        
        required_groups = {
            "registry_delete": "SoftwareRemoval_RegistryDelete",
            "file_delete": "SoftwareRemoval_FileDelete",
            "service_control": "SoftwareRemoval_ServiceControl"
        }
        
        for perm in required_permissions:
            group = required_groups.get(perm)
            if group and not self._user_in_group(conn, service_account_name, group):
                raise PermissionError(
                    f"Account {service_account_name} not in group {group}"
                )
    
    def _create_temporary_token(self, service_account_name: str, validity_seconds: int) -> str:
        """Create temporary access token with expiration"""
        
        import jwt
        
        payload = {
            "service_account": service_account_name,
            "issued_at": datetime.utcnow().timestamp(),
            "expires_at": (datetime.utcnow() + timedelta(seconds=validity_seconds)).timestamp()
        }
        
        token = jwt.encode(
            payload,
            os.getenv("TOKEN_SECRET_KEY"),
            algorithm="HS256"
        )
        
        return token
    
    def _audit_log_credential_access(self, service_account: str, action: str, permissions: list):
        """Log all credential access for audit trail"""
        
        log_entry = {
            "timestamp": datetime.utcnow().isoformat(),

            "action": action,
            "permissions_requested": permissions,
            "caller": self._get_caller_info(),
            "ip_address": self._get_request_ip()
        }
        
        # Log to immutable audit database
        # Also alert if unusual access pattern

```python
# email_parser.py

class EmailSoftwareParser:
    """
    Parse emails containing unauthorized software removal requests
    Extracts software name, version, urgency, and target devices
    """
    
    def parse_email(self, email_message: dict) -> dict:
        """
        Parse email and extract structured software removal request
        
        Supported formats:
        1. Structured format (key: value)
        2. Free text with NLP extraction
        3. Attachment (CSV, JSON)
        """
        
        # Try structured format first
        parsed = self._parse_structured(email_message)
        
        # Fallback to NLP-based extraction
        if not parsed.get("software_name"):
            parsed = self._parse_freetext_nlp(email_message)
        
        # Try attachments
        if parsed.get("attachment_data"):
            parsed = self._parse_attachment(email_message, parsed)
        
        # Validate extracted data
        self._validate_parsed_data(parsed)
        
        return parsed
    
    def _parse_structured(self, email_message: dict) -> dict:
        """Parse structured format: Software: X, Version: X, etc."""
        
        body = email_message.get("body", "")
        
        # Use regex to extract key-value pairs
        import re
        
        result = {}
        
        # Software name
        match = re.search(r'Software:\s*([^\n]+)', body, re.IGNORECASE)
        if match:
            result['software_name'] = match.group(1).strip()
        
        # Version
        match = re.search(r'Version:\s*([^\n]+)', body, re.IGNORECASE)
        if match:
            result['software_version'] = match.group(1).strip()
        
        # Device IDs
        device_ids = re.findall(r'DEV-\d{4}|[A-Z]+-[A-Z0-9]+', body)
        if device_ids:
            result['device_ids'] = list(set(device_ids))  # Deduplicate
        
        # Reason
        match = re.search(r'Reason:\s*([^\n]+)', body, re.IGNORECASE)
        if match:
            result['removal_reason'] = match.group(1).strip()
        
        # Urgency
        urgency_match = re.search(
            r'(CRITICAL|IMMEDIATE|HIGH|MEDIUM|LOW)',
            email_message.get("subject", ""),
            re.IGNORECASE
        )
        if urgency_match:
            result['urgency'] = urgency_match.group(1).lower()
        
        return result
    
    def _parse_freetext_nlp(self, email_message: dict) -> dict:
        """
        Use NLP to extract software details from free text email
        This is a fallback for unstructured emails
        """
        
        from transformers import pipeline
        
        # NLP models
        ner_model = pipeline("ner", model="bert-base-multilingual-cased")
        qa_model = pipeline("question-answering")
        
        body = email_message.get("body", "")
        subject = email_message.get("subject", "")
        
        result = {}
        
        # Extract entities from subject
        entities = ner_model(subject)
        for entity in entities:
            if entity['entity_group'] == 'MISC':  # Likely software name
                result['software_name'] = entity['word']
        
        # Question-answering for details
        questions = [
            "What software needs to be removed?",
            "What version should be removed?",
            "How urgent is this?",
            "Which devices are affected?"
        ]
        
        for question in questions:
            answer = qa_model(question, body)
            if answer['score'] > 0.5:
                if "software" in question:
                    result['software_name'] = answer['answer']
                elif "version" in question:
                    result['software_version'] = answer['answer']
                elif "urgent" in question:
                    result['urgency'] = self._classify_urgency(answer['answer'])
                elif "device" in question:
                    result['device_ids'] = self._extract_device_ids(answer['answer'])
        
        return result
    
    def _parse_attachment(self, email_message: dict, base_parsed: dict) -> dict:
        """
        Parse attachment if present
        Supports CSV and JSON formats
        """
        
        for attachment in email_message.get("attachments", []):
            filename = attachment.get("filename", "")
            
            if filename.endswith(".csv"):
                # Parse CSV
                import csv
                data = csv.DictReader(attachment['content'].splitlines())
                
                # Expected columns: device_id, software_name, software_version
                devices = []
                for row in data:
                    devices.append(row.get('device_id'))
                    if 'software_name' in row:
                        base_parsed['software_name'] = row['software_name']
                    if 'software_version' in row:
                        base_parsed['software_version'] = row['software_version']
                
                base_parsed['device_ids'] = devices
            
            elif filename.endswith(".json"):
                # Parse JSON
                import json
                data = json.loads(attachment['content'])
                base_parsed.update(data)
        
        return base_parsed
    
    def _validate_parsed_data(self, parsed: dict):
        """Validate required fields are present"""
        
        required_fields = ['software_name', 'software_version']
        
        for field in required_fields:
            if not parsed.get(field):
                raise ValueError(f"Missing required field: {field}")
        
        # Validate version format
        import re
        if not re.match(r'[\d.]+', parsed['software_version']):
            raise ValueError(f"Invalid version format: {parsed['software_version']}")
```
