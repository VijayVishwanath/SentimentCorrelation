# KB-NET-003 - Home ISP / last-mile quality

## Symptoms
Connection unstable at home; fine in the office.

## Telemetry signature
Remote work mode, elevated latency only off-site.

## Diagnosis steps
1. Run the home-network assessment (speed, jitter, router age).
2. Confirm whether the issue reproduces on a wired connection.

## Remediation
1. Provide router placement / 5GHz guidance.
2. Offer a 4G/5G fallback hotspot for critical roles.
3. Escalate to the ISP stipend programme where available.

## Expected outcome
Removes a class of tickets that device fixes cannot solve.

## Verify
Close only when the primary telemetry signal is back below its warn threshold and no repeat contact is logged for 7 days (see KB-GEN-001).
